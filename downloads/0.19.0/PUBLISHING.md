# Uploading the release

Publish your project source on GitHub, keeping LICENSE and attribution. Upload
the .deb, source ZIP, INSTALL.md and SHA256SUMS as GitHub Release attachments.
The source ZIP also provides all sources needed to build this Linux version.
Avoid uploading temporary build outputs, personal configuration or recording
files as repository source. The downloads/ folder contains generated deliverables.

For a paid storefront, upload the same .deb and offer the source ZIP alongside
it. Include installation instructions and a public link to the GitHub release.
Label it Linux Mint 22.3 amd64 tested, public beta. Do not advertise all Linux
distributions as tested. A suggested description is:

“Pay once to support development. Keep this version forever—no subscription or
activation. The same app and source code are also available free on GitHub.”

Link the free download visibly. Keep the exact corresponding source archive
available with each version's installer, not only a changing latest source tree.
